## Key failure modes

### 1. Regressions in high-point questions (Q210, Q330)
Two 500–1000-point questions that v1.0 got right (BSTOLL-L, mkraeusen) were wrong in v1.1. The LLMCompiler planner appears to have generated sub-optimal plans for these compared to the v1.0 ReAct loop's iterative refinement.

### 2. Password / credential questions still wrong
Q303 (ilovedavidverve) found the wrong credential — Linux tomcat7 password instead of the Windows endpoint password. The Senior's Splunk scope needs to be constrained to the correct endpoint when the question specifies it.

### 3. CVE identification wrong
Q332 and Q333: the Senior found CVE-related SPL hits but identified wrong CVEs. These require matching specific exploit techniques to CVE numbers, which demands more precise vulnerability knowledge than the dataset directly provides.

### 4. Arithmetic off-by-small
Q206 (size), Q224 (avg length), Q331 (IQR) all involve SPL math where a small formula error produces a plausible but wrong value. The extractor is now less likely to add prefixes (Q331 no longer gets "UF = "), but the underlying calculation is still wrong.

### 5. MD5 of empty file (Q307)
The agent submitted `d41d8cd98f00b204e9800998ecf8427e` — the MD5 hash of an empty file — suggesting it constructed or found an empty file reference rather than hashing the actual scanning tool binary.
